# Bug Bounty Report Template

To submit a vulnerability report, please use the following template in your email. Copy and fill in the placeholders with your details.
Once completed, please send your report and any attachments to [contract@torch.finance](mailto:contract@torch.finance)

---

**Subject:** [Bug Bounty Report] - [Brief Vulnerability Description]

**Vulnerability Description:**  
Provide a clear textual description of the vulnerability type, impact.

**Reproduction Steps:**  
Please provide detailed steps to reproduce the issue, along with a clear explanation of the actual behavior versus the expected outcome.

**PoC Proof:**  
Please provide a proof of concept (PoC) that demonstrates the vulnerability described in the reproduction steps above. The PoC should clearly show how the issue occurs and what the results are.

- If you are using [our PoC template](https://github.com/torch-core/bug-bounty/tree/main/poc), please attach the modified script (e.g., xxx-vuln.spec.ts).
- If you are not using the template, be sure to include a clear and detailed explanation, such as a custom script, console output, or other supporting materials.
- To help us understand and verify the issue more efficiently, you may also paste the execution results directly into the report.

### **Additional Notes (Optional)**

### **Attachments Policy**

To protect both researchers and our team, we strictly enforce the following rules:

- ✅ Only the following file types are allowed as attachments:
  `.ts`, `.py`, `.txt`, `.md`

- ❌ Do not include any links in your report, including image links.

- ✅ If you need to include a screenshot or diagram, **embed it directly inside the email**.

Reports that fail to follow these security rules may be rejected without review.
